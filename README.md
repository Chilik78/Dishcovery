# Dishcovery

Dishcovery — это приложение для поиска, просмотра и подбора рецептов, которое превращает вопрос «Что приготовить?» из ежедневной головной боли в увлекательное открытие.

## О проекте

Dishcovery помогает быстро найти подходящее блюдо с учётом текущего запроса пользователя и продуктов, которые уже есть дома.

Проект состоит из двух основных частей:

- **Client** — веб-интерфейс на Next.js/React;
- **Server** — REST API на FastAPI, которое получает и нормализует данные рецептов и предоставляет их клиентскому приложению.

Источником рецептов на текущем этапе является **TheMealDB**.

## Основные возможности

### Поиск и фильтрация

Поддерживаются:

- поиск по названию;
- фильтрация по кухне;
- фильтрация по типу блюда;
- фильтрация по ингредиенту;
- выбор продуктов, которые есть дома;
- режим «только доступные» для Pantry Mode;
- комбинирование нескольких фильтров;
- постраничная загрузка рецептов;
- автоматическая подгрузка следующей страницы при прокрутке.

### Pantry Mode

Пользователь выбирает продукты, которые уже есть дома. Выбор продуктов не вызывает запрос к серверу после каждого клика.

После подтверждения клиент отправляет единый запрос:

```text
GET /api/recipes?pantry=Chicken,Basil&...
```

В режиме `only_pantry=true` сервер оставляет только рецепты, которые можно приготовить из выбранных продуктов, и рассчитывает недостающие ингредиенты.

### Карточка рецепта

Клиент получает от API:

- название;
- кухню;
- тип блюда;
- изображение;
- ингредиенты и меры;
- инструкции;
- ссылку на источник;
- ссылку на YouTube, если она предоставлена;
- информацию о недостающих ингредиентах при использовании Pantry Mode.

## Требования

Для запуска проекта необходимы:

- Node.js 20+;
- npm;
- Python 3.11+;
- доступ к интернету для запросов к TheMealDB.

## Запуск Server

Перейдите в каталог сервера:

```bash
cd server
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows:

```powershell
.venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите FastAPI:

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8001
```

После запуска:

```text
API:     http://localhost:8001
Swagger: http://localhost:8001/docs
```

## Запуск Client

В отдельном терминале:

```bash
cd client
npm install
```

Создайте `.env.local`:

```env
NEXT_PUBLIC_API_URL=http://localhost:8001/api
```

Запустите:

```bash
npm run dev
```

Клиент будет доступен по адресу:

```text
http://localhost:3000
```

## API

Основные endpoints:

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка API и upstream |
| GET | `/api/meta` | Кухни, типы и ингредиенты |
| GET | `/api/pantry/ingredients` | Список ингредиентов |
| GET | `/api/recipes` | Поиск и подборка рецептов |
| GET | `/api/recipes/{id}` | Детальная информация о рецепте |
| GET | `/api/recipes/random` | Случайный рецепт |

Пример:

```http
GET /api/recipes?q=pasta&cuisine=Итальянская&ingredient=Tomato&limit=24&offset=0
```

Следующая страница:

```http
GET /api/recipes?q=pasta&cuisine=Итальянская&ingredient=Tomato&limit=24&offset=24
```

Ответ списка:

```json
{
  "items": [],
  "total": 120
}
```

`total` показывает количество уникальных рецептов, соответствующих текущей выборке.

## Фильтрация

Параметры `/api/recipes`:

| Параметр | Описание |
|---|---|
| `q` | Поиск по названию |
| `cuisine` | Кухня |
| `type` | Тип блюда |
| `ingredient` | Ингредиент |
| `pantry` | Список имеющихся ингредиентов через запятую |
| `only_pantry` | Оставить только доступные рецепты |
| `limit` | Размер страницы |
| `offset` | Смещение страницы |

Фильтры можно комбинировать.

Например:

```http
GET /api/recipes?q=chicken&cuisine=Итальянская&type=Ужин&ingredient=Garlic
```

## Пагинация

TheMealDB не предоставляет полноценную пагинацию для нашего сценария, поэтому пагинация реализована на стороне Dishcovery API.

Клиент получает данные порциями:

```text
offset=0
   ↓
24 рецепта
   ↓
offset=24
   ↓
ещё 24
   ↓
offset=48
   ↓
...
```

При прокрутке Client автоматически загружает следующую страницу.

## Важное ограничение текущего источника

TheMealDB не предоставляет достоверные значения для:

- времени приготовления;
- калорийности;
- БЖУ;
- сложности приготовления.

Поэтому эти значения не генерируются искусственно и не являются mock-данными.

Для полноценной реализации этих фильтров в будущем потребуется отдельный источник nutrition/time/difficulty или собственная база данных.

## Разработка

Рекомендуемый порядок запуска:

```text
1. Запустить FastAPI
2. Проверить /api/health

4. Открыть http://localhost:3000
```

При изменении API-контракта сначала обновляйте схемы Server, затем типы и API-клиент в Client.
